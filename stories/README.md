# Game Stories

Add one Lua file per game. The filename must match the game key Vita Launcher
derives from the title ID, ROM filename, or title. Start with `_template.lua`.

Each entry uses short, original text in three player-focused sections:

- `synopsis`: what makes the game distinct.
- `gameplay`: how it feels to play, including its loop, pace, and challenge.
- `ideal_for`: who should choose it from a large library.
