# Game Stories

Add one Lua file per game. The filename must match the game key Vita Launcher
derives from the title ID, ROM filename, or title. Start with `_template.lua`.

Each entry uses up to four short, original `highlights` written like the useful
parts of a game package back cover:

- A premise or setting that gives the game context.
- The primary play mechanic or activity.
- Its scope, variety, or standout feature.
- The kind of player it suits.

The game title is already displayed in the details header, so do not repeat it
in a highlight. Keep each point specific, practical, and easy to scan.
